# mazalmk – site files

Hosted on **Cloudflare Pages** (advanced mode). Deploy by connecting the GitHub repo in
Cloudflare → Workers & Pages → Create → Pages, with no build command and output directory `/` (this folder).

```
index.html                    the marketplace (Macedonian, Albanian, English; phone-friendly)
help|safety|privacy|terms|contact.html   info pages in 3 languages (generated by pages.py)
admin.html                    admin panel (open /admin.html, log in with your admin account)
icon*.png, icon.svg           app icons (add to home screen)
manifest.webmanifest          app manifest
_worker.js                    handles /oglas/<id>, /sitemap.xml, /robots.txt and the app routes
_routes.json                  which routes run through _worker.js
_headers                      security headers; /admin.html is noindex + no-store
```

Contact e-mail on the info pages: edit CONTACT_EMAIL in pages.py and run `python3 pages.py`,
or search the 5 pages for YOUR-EMAIL@example.com.

The Supabase address and publishable key are near the top of `index.html`, `admin.html` and `_worker.js`.
Never put the `service_role` / secret key in any of them.

Netlify-only files (`listing.mjs`, `sitemap.mjs`, `robots.mjs`, `sitemap.xml.js`, `robots.txt.js`) are no longer needed and can be deleted.
